Your listening setup

SongRec and ShazamIO check the selected tab's audio after 3 seconds, then uses longer samples up to 12 seconds if needed. Listening continues during recognition and stops on a match. The local helper sends audio fingerprints to Shazam. AudioTag sends one 15-second sample. Song and anime queries go to AnisongDB, AnimeThemes (fallback), and AniList. No microphone recording or analytics.

SongRec and ShazamIO use the same local helper and Shazam’s online catalog. Both use unofficial endpoints and require no API key. To install SongRec on Windows, run scripts/setup-songrec.ps1 from the project folder.

Create your key in your AudioTag account. Never put it in source code or GitHub.

Otherwise the key lasts for this browser session. Device storage is not an encrypted credential vault.

The extension checks remaining free seconds before each upload and refuses paid recognition. AudioTag's free allowance and renewal are account-dependent.

Local helper

One-time automatic launcher setup: run scripts/install-native-helper.ps1 from this project folder, then reload Anioto. Manual startup is also available:

With the native helper installed, opening Anioto starts local recognition as needed, including after a reboot. It does not start at Windows sign-in or browser startup.
